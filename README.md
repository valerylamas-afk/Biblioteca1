# Sistema de Gestión de Biblioteca

Proyecto desarrollado en C# y .NET 10 para la gestión de una biblioteca mediante consola.

Se implementó:

* Registro y gestión de libros.
* Registro de usuarios.
* Búsqueda, listado y eliminación de libros.
* Registro de préstamos y devoluciones.
* Consulta de libros disponibles.
* Consulta de préstamos activos.
* Validación de libros y usuarios duplicados.
* Manejo de errores mediante excepciones.
* Uso de LINQ para realizar búsquedas, filtros, ordenamientos y consultas.
* Uso de clases, listas, arrays, records e interfaces.
* Menú interactivo mediante consola.

El proyecto fue trabajado con Git y GitHub, utilizando la rama `feature/prestamos` y un Pull Request para integrarla a `main`.
